# 🏡 Previsão de Preços de Imóveis com Regressão Linear

Este projeto tem como objetivo construir um modelo de regressão linear para estimar o preço de um imóvel com base em características fornecidas. Utilizamos a base de dados `USA_Housing.csv` e ferramentas de análise e modelagem em Python.

## 🎯 Objetivo

Criar um modelo preditivo que estime o valor de um imóvel com base em variáveis como:
- Média de renda por área
- Média de idade da casa
- Número de quartos e banheiros
- População da área

## 🧪 Etapas do Projeto

- **Importação de Dados**
  - Leitura da base `USA_Housing.csv` com `pandas`

- **Análise Exploratória**
  - Verificação de valores nulos
  - Visualização dos dados

- **Construção do Modelo**
  - Aplicação de Regressão Linear
  - Treinamento e teste do modelo

- **Avaliação**
  - Métricas de desempenho do modelo

## 🛠️ Tecnologias Utilizadas

- Python
- Pandas
- Scikit-learn
- Jupyter Notebook
